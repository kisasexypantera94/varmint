# Running Resident Evil 3: Raccoon City Demo in Varmint

Resident Evil 3: Raccoon City Demo is playable in Varmint using Neptune.

## Quick setup

Use the following configuration:

```text
Steam App IDs: 1173690
Profile:        default
Recommendation: Recommended
Evidence:       Tested
Setup:          Automatic
Runtime:        Proton
Proton version: Proton Experimental
Renderer:       Neptune
Host backend:    DXMT
Launch options: varmint-graphics neptune %command%
```

### Enable Neptune

Set the Steam launch options to:

```text
varmint-graphics neptune %command%
```

No additional setup is required.
