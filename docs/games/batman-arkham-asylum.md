# Running Batman: Arkham Asylum in Varmint

Batman: Arkham Asylum is playable in Varmint using Venus.

## Quick setup

Use the following configuration:

```text
Proton version: Proton 10.0
Renderer:       Venus
```

### 1. Select Proton 10

In Steam:

1. Open **Properties** for Batman: Arkham Asylum.
2. Open **Compatibility**.
3. Under **Select compatibility tool**, select **Proton 10.0**.

No additional launch options are required.

## Tested configuration

```text
Batman: Arkham Asylum
Proton 10.0
Venus
```
