# Running FINAL FANTASY XV WINDOWS EDITION PLAYABLE DEMO in Varmint

FINAL FANTASY XV WINDOWS EDITION PLAYABLE DEMO is playable in Varmint using Neptune.

## Quick setup

Use the following configuration:

```text
Steam App IDs: 671210
Profile:        default
Recommendation: Recommended
Evidence:       Tested
Setup:          Automatic
Runtime:        Proton
Proton version: Proton Experimental
Renderer:       Neptune
Host backend:    DXMT
Launch options: varmint-graphics neptune %command%
```

### 1. Enable Neptune

Set the Steam launch options to:

```text
varmint-graphics neptune %command%
```

No additional setup is required.
