# Running Assassin's Creed II in Varmint

Assassin's Creed II is playable in Varmint using Proton 9.

Proton 10 currently fails during startup in the Ubisoft launcher, so Proton 9 should be selected explicitly.

## Quick setup

Use the following configuration:

```text
Proton version: Proton 9.0
```

### 1. Select Proton 9

In Steam:

1. Open **Properties** for Assassin's Creed II.
2. Open **Compatibility**.
3. Enable **Force the use of a specific Steam Play compatibility tool**.
4. Select **Proton 9.0**.

### 2. Start the game

Launch Assassin's Creed II normally from Steam.

The Ubisoft launcher can be unreliable on startup. If it shows an error such as `Failed to...`, click **Try Again** a few times. It usually starts successfully after that.

If the launcher says it could not verify the game, click **Stop**, then start the game again from Steam.

No additional launch options or configuration is required for the tested setup.
