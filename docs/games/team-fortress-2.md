# Running Team Fortress 2 in Varmint

Team Fortress 2 is playable in Varmint using the native Linux build with the Vulkan renderer.

## Quick setup

Use the following configuration:

```text
Runtime:           Native Linux
Renderer:          Vulkan
Graphics settings: Default
```

### 1. Use the native Linux version

In Steam, leave **Force the use of a specific Steam Play compatibility tool** disabled.

### 2. Use Vulkan

Launch Team Fortress 2 normally from Steam. The native Linux version uses Vulkan by default.

Do not select the legacy OpenGL renderer.

### 3. Keep the default settings

The default in-game graphics settings work without additional configuration.

## Tested configuration

```text
Team Fortress 2
Native Linux
Vulkan
Default graphics settings
```
