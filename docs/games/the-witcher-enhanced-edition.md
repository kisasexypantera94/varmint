# Running The Witcher: Enhanced Edition in Varmint

The Witcher: Enhanced Edition is playable in Varmint using Proton 9.

## Quick setup

Use the following configuration:

```text
Proton version: Proton 9.0
```

### 1. Select Proton 9

In Steam:

1. Open **Properties** for The Witcher: Enhanced Edition.
2. Open **Compatibility**.
3. Enable **Force the use of a specific Steam Play compatibility tool**.
4. Select **Proton 9.0**.

### 2. Start the game

Launch The Witcher: Enhanced Edition normally from Steam.

No additional DXVK, WineD3D or Vulkan configuration is required.

## Tested configuration

```text
The Witcher: Enhanced Edition
Steam App ID 20900
Proton 9.0
DirectX 9 through DXVK
```
