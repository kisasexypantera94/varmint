# Running Risk of Rain 2 in Varmint

Risk of Rain 2 is playable in Varmint using Venus.

This configuration is based on a user report and has not been tested directly by the project.

## Quick setup

Use the following configuration:

```text
Steam App IDs: 632360
Profile:        default
Recommendation: Recommended
Evidence:       Reported
Setup:          Automatic
Runtime:        Proton
Proton version: Proton 10.0
Renderer:       Venus
Host backend:    MoltenVK
Launch options: Unchanged
```

### 1. Select Proton 10

In Steam:

1. Open **Properties** for Risk of Rain 2.
2. Open **Compatibility**.
3. Under **Select compatibility tool**, select **Proton 10.0**.

No additional launch options are required.

## Reported configuration

```text
Risk of Rain 2
Proton 10.0
Venus
```
