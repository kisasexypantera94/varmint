# Running The Dark Pictures Anthology: The Devil in Me Demo in Varmint

The Dark Pictures Anthology: The Devil in Me Demo is playable in Varmint using Neptune.

## Quick setup

Use the following configuration:

```text
Steam App IDs: 1959910
Profile:        demo
Recommendation: Recommended
Evidence:       Tested
Setup:          Automatic
Runtime:        Proton
Proton version: Proton Experimental
Renderer:       Neptune
Host backend:    DXMT
Launch options: varmint-graphics neptune %command%
```

### 1. Enable Neptune

Set the Steam launch options to:

```text
varmint-graphics neptune %command%
```

No additional setup is required.

The Dark Pictures Anthology: The Devil in Me Demo
