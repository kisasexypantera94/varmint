# Running Red Comrades Reloaded games in Varmint

The following games are playable in Varmint using Proton 10:

- Red Comrades 2: For the Great Justice. Reloaded
- Red Comrades Save the Galaxy: Reloaded

## Quick setup

Use the following configuration:

```text
Proton version: Proton 10.0
```

## Select Proton 10

In Steam:

1. Open **Properties** for the game.
2. Open **Compatibility**.
3. Enable **Force the use of a specific Steam Play compatibility tool**.
4. Select **Proton 10.0**.

Launch the game normally from Steam.

No additional launch options or configuration are required.
