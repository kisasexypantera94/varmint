# Running Ghostrunner Demo in Varmint

Ghostrunner Demo is playable in Varmint using Neptune.

## Quick setup

Use the following configuration:

```text
Proton version: Proton Experimental
Renderer:       Neptune
Launch options: varmint-graphics neptune %command%
```

### 1. Enable Neptune

Set the Steam launch options to:

```text
varmint-graphics neptune %command%
```

### 2. Use DirectX 11

When Steam asks which version to start, select **DirectX 11**.

## Tested configuration

```text
Ghostrunner Demo
Proton Experimental
DirectX 11
Neptune
```
