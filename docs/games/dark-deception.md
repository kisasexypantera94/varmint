# Running Dark Deception in Varmint

Dark Deception is playable in Varmint using Neptune.

## Quick setup

Use the following configuration:

```text
Steam App IDs: 332950
Profile:        default
Recommendation: Recommended
Evidence:       Tested
Setup:          Automatic
Runtime:        Proton
Proton version: Proton Experimental
Renderer:       Neptune
Host backend:    DXMT
Launch options: varmint-graphics neptune %command%
```

### 1. Enable Neptune

Set the Steam launch options to:

```text
varmint-graphics neptune %command%
```

No additional setup is required.

## Tested configuration

```text
Dark Deception
Proton Experimental
DirectX 11
Neptune
```
