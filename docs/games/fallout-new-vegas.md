# Running Fallout: New Vegas in Varmint

Fallout: New Vegas is playable in Varmint using Proton 10.

## Quick setup

Use the following configuration:

```text
Proton version: Proton 10
```

### 1. Select Proton 10

In Steam:

1. Open **Properties** for Fallout: New Vegas.
2. Open **Compatibility**.
3. Under **Select compatibility tool**, select **Proton 10**.

### 2. Start the game

Launch Fallout: New Vegas normally from Steam.

No additional setup is required.

## Tested configuration

```text
Fallout: New Vegas
Proton 10
DirectX 9
Venus
```
