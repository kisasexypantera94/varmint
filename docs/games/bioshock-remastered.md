# Running BioShock Remastered in Varmint

BioShock Remastered is playable in Varmint using Venus and Proton 10.

## Quick setup

Use the following configuration:

```text
Steam App IDs: 409710
Profile:        default
Recommendation: Recommended
Evidence:       Tested
Setup:          Automatic
Runtime:        Proton
Proton version: Proton 10.0
Renderer:       Venus
Host backend:    MoltenVK
Launch options: Unchanged
```

### 1. Select Proton 10

In Steam:

1. Open **Properties** for BioShock Remastered.
2. Open **Compatibility**.
3. Under **Select compatibility tool**, select **Proton 10.0**.

### 2. Start the game

Launch BioShock Remastered normally from Steam. Venus is the default renderer,
so no launch options are required.

## Tested configuration

BioShock Remastered
Steam App ID 409710
Proton 10.0
