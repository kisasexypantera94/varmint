# Running Garry's Mod in Varmint

Garry's Mod is playable in Varmint using Proton 10.

## Quick setup

Use the following configuration:

```text
Proton version: Proton 10.0
```

### 1. Select Proton 10

In Steam:

1. Open **Properties** for Garry's Mod.
2. Open **Compatibility**.
3. Enable **Force the use of a specific Steam Play compatibility tool**.
4. Select **Proton 10.0**.

### 2. Start the game

Launch Garry's Mod normally from Steam.

No additional launch options, DXVK, Wine or Vulkan configuration is required for the tested setup.

## Tested configuration

```text
Garry's Mod
Proton 10.0
DirectX 9 through DXVK
```
