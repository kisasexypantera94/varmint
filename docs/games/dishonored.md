# Running Dishonored in Varmint

Dishonored is playable in Varmint using Proton 10 with the default game settings.

## Quick setup

Use the following configuration:

```text
Proton version:    Proton 10
Graphics settings: Default
Launch options:    None
```

### 1. Select Proton 10

In Steam:

1. Open **Properties** for Dishonored.
2. Open **Compatibility**.
3. Under **Select compatibility tool**, select **Proton 10**.

### 2. Start the game

Launch Dishonored normally from Steam and keep the default graphics settings.

No additional setup is required.

## Tested configuration

```text
Dishonored
Proton 10
Default graphics settings
No launch options
```
