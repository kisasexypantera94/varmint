# Running Dishonored in Varmint

Dishonored is playable in Varmint using Proton 9 with the default game settings.

## Quick setup

Use the following configuration:

```text
Proton version:    Proton 9.0
Graphics settings: Default
Launch options:    None
```

### 1. Select Proton 9

In Steam:

1. Open **Properties** for Dishonored.
2. Open **Compatibility**.
3. Enable **Force the use of a specific Steam Play compatibility tool**.
4. Select **Proton 9.0**.

### 2. Start the game

Launch Dishonored normally from Steam and keep the default graphics settings.

No additional launch options or DXVK configuration are required.

## Tested configuration

```text
Dishonored
Proton 9.0
Default graphics settings
No launch options
```
