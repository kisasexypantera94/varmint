# Running SCP – Containment Breach in Varmint

SCP – Containment Breach is playable in Varmint using Proton 10.

## Quick setup

Use the following configuration:

```text
Proton version: Proton 10.0
```

### 1. Select Proton 10

In Steam:

1. Open **Properties** for SCP – Containment Breach.
2. Open **Compatibility**.
3. Enable **Force the use of a specific Steam Play compatibility tool**.
4. Select **Proton 10.0**.

### 2. Start the game

Launch SCP – Containment Breach normally from Steam.

No additional launch options or configuration is required for the tested setup.

## Tested configuration

```text
SCP – Containment Breach
Proton 10.0
```
