# Running Fallout 3 in Varmint

Fallout 3 is playable in Varmint using Proton 10.

## Quick setup

Use the following configuration:

```text
Proton version: Proton 10
```

### 1. Select Proton 10

In Steam:

1. Open **Properties** for Fallout 3.
2. Open **Compatibility**.
3. Under **Select compatibility tool**, select **Proton 10**.

### 2. Start the game

Launch Fallout 3 normally from Steam.

No additional setup is required.

## Tested configuration

```text
Fallout 3
Proton 10
DirectX 9
Venus
```
