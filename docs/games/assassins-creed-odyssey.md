# Running Assassin's Creed Odyssey in Varmint

Assassin's Creed Odyssey is playable in Varmint using Neptune.

## Quick setup

Use the following configuration:

```text
Proton version: Proton 10.0
Renderer:       Neptune
Launch options: varmint-graphics neptune %command%
```

### 1. Select Proton 10

In Steam:

1. Open **Properties** for Assassin's Creed Odyssey.
2. Open **Compatibility**.
3. Under **Select compatibility tool**, select **Proton 10.0**.

### 2. Enable Neptune

Set the following Steam launch options:

```text
varmint-graphics neptune %command%
```

No additional configuration is required.

## Tested configuration

```text
Assassin's Creed Odyssey
Proton 10.0
DirectX 11
Neptune
```
