# Running Deus Ex: Human Revolution in Varmint

Deus Ex: Human Revolution is playable in Varmint using Proton 9 with the DirectX 11 renderer and default game settings.

## Quick setup

Use the following configuration:

```text
Steam App IDs: 238010
Profile:        default
Recommendation: Recommended
Evidence:       Tested
Setup:          Automatic
Runtime:        Proton
Proton version:    Proton 9.0
Renderer:          Venus
Host backend:    MoltenVK
Graphics settings: Default
Launch options:    None
```

### 1. Select Proton 9

In Steam:

1. Open **Properties** for Deus Ex: Human Revolution.
2. Open **Compatibility**.
3. Under **Select compatibility tool**, select **Proton 9.0**.

### 2. Start the game

Launch the game normally with the default graphics settings.

No additional setup is required.
